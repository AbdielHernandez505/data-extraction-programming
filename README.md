# Data Extraction Programming

### 5th Semester

This repository contains the activities, exercises, and projects developed during the **Data Extraction Programming** course.

The main purpose of this repository is to practice Python programming for data extraction, data processing, web scraping, database connection, and data analysis using different tools and libraries.

## Repository Structure

| Folder | Description |
|---|---|
| `Examples/` | Class examples and practice files related to pandas, data cleaning, MySQL, APIs, Selenium, dashboards, Plotly charts, datasets, and images. |
| `Meta 1.1 - Lists_Tuples_Practice/` | Exercises using lists, tuples, stacks, classes, and basic data structures. |
| `Meta 1.2 – Solve Dictionary and Set Problems/` | Practice with dictionaries and sets, including a product inventory exercise. |
| `Meta 1.3 - Implement a scraping process using Selenium/` | Web scraping activity using Selenium, including screenshots as evidence. |
| `Meta 1.4 - Analyze and Understand Data Extraction Process/` | Data extraction process using Selenium and BeautifulSoup, including a generated dataset. |
| `Meta 2.2 Processing of Duplicate and Null Data/` | Exercises focused on handling duplicate values, null data, and preprocessing. |
| `Meta 2.3 - Develop applications that connect to a database/` | Python and MySQL activity focused on creating tables, inserting records, and running queries. |
| `Meta 3.1 - Implement functions to group, transform, and summarize data/` | pandas activity using `map()`, `groupby()`, calculated columns, and `pivot_table()`. |
| `Meta 3.2 Implement Indexes and loc and iloc functions in pandas/` | pandas activity focused on selecting and modifying data using `loc` and `iloc`. |
| `Meta 3.3 - Examen Unidad 3/` | Unit 3 exam exercises using pandas for data analysis and processing. |

## How to Run the Files

Most Python files can be executed directly from the terminal.

Example:

```bash
python file_name.py
```

Some files are inside folders with spaces in their names, so it is recommended to use quotation marks.

Example:

```bash
python "Meta 3.1 - Implement functions to group, transform, and summarize data/store_analysis_pandas.py"
```

For the MySQL activity, make sure that MySQL is running and that the database configuration inside the script matches your local setup.
